# 中文文本局部改写

这个 skill 只处理已有文本的局部改写，目标是减少模板化、机械化和欧式中文，同时保留原文的事实、论点、语气和证据。

## 目录

- `references/strategies.md`：两轮改写策略
- `references/anti-patterns.md`：通用 AI 痕迹和表达问题
- `references/checklist.md`：改写后的质量检查
- `references/examples.md`：改写示例

## 模式

- `academic_mode`：论文、摘要、课程作业和正式技术文档。保持术语、论证和引用稳定，不主动增加第一人称。
- `narrative_mode`：博客、复盘和经验文章。保留原文已有的第一人称、具体经历、犹豫和判断来路，不把叙述抹平成中性说明。

用户没有说明模式时，根据文本用途判断。仍然不确定时先询问。

## 使用顺序

1. 判断文本模式和本次改写轮次
2. 读取 `references/strategies.md` 中对应的策略
3. 读取输入文本，按自然段切分。单段过长时再按句子切分
4. 只改当前轮次命中的问题
5. 读取 `references/checklist.md` 做内部检查
6. 按用户指定的输出格式交付

## 约束

- 不新增事实、数据、案例、文献、引文或实验结论
- 保留专业术语、逻辑关系、编号结构、段落结构和关键结论
- 不整篇重写，只改需要改的段落
- 每次调用只执行一轮，后续轮次必须基于上一轮结果
- 改写损伤事实、证据或原文声音时立即停止并报告
- 连续两轮没有明显改善，或改写开始损伤语义时停止自动回环

## 输出

- `rewrite_only`：只输出改写后的正文
- `review_report`：输出改写正文、命中问题、评分和下一轮建议

这个 skill 不包含任何特定作者的固定语气、禁用表达或个人经历。作者风格规则应由调用方按需提供。
