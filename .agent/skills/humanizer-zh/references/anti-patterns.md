# 通用 AI 痕迹与表达问题

这份清单只描述可观察的问题，不规定某个作者的固定语气。是否修改要结合文本用途、事实和上下文判断。

## 篇章级问题

- 每一节都用相同的总结句收尾
- 先给正确结论，再把经历和证据硬塞回去
- 用“第一、第二、第三”制造均匀的三段式结构
- 每句话都在下结论，缺少具体动作、过程和停顿
- 文章为了完整而补出原文没有提供的因果

## 常见表达问题

- 空洞过渡：综上所述、总而言之、值得注意的是、深入探讨
- 宣传腔：至关重要、不可小觑、全面赋能、显著提升
- 模糊归因：有研究表明、专家认为、行业普遍认为
- 机械对举：不是 X 而是 Y、与其说 X 不如说 Y
- 机械转折：后来我才发现、这让我深刻认识到、由此可见
- 过量元话语：下面我们来看看、接下来将介绍、正如上文所述
- 过量加粗、引号、破折号或括号

## 欧式中文

优先检查弱动词和名词化表达，例如“进行分析”“开展管理”“作出决定”“予以考虑”“实施整改”。能直接使用动词时，改成“分析”“管理”“决定”“考虑”“整改”。技术术语或正式文体确实需要时可以保留。

## 叙述文本

- 不要为了显得客观而删除原文必要的第一人称
- 不要把具体失败改成顺利完成的流程
- 不要用心理戏替代动作、对话或证据
- 不要把不确定判断改写成确定事实

## 修改方法

1. 先定位具体句子和问题类型
2. 用事实、动作、时间或证据替代空洞判断
3. 检查改写是否保留原文信息和语气
4. 如果缺少事实，停下来询问，不用常识补齐
